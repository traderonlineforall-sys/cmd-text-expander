# cmd

Portable Windows text expander.

Recommended for Chrome / WhatsApp / Outlook: use **Ctrl + Space** mode.

Usage:
1. Run `cmd.exe`.
2. Add or import snippets.
3. Type the keyword in any text field.
4. Press `Ctrl + Space`.

Other modes:
- Automatic: keyword then Space / Enter / Tab.
- Custom trigger: keyword + your custom trigger, e.g. `;hi؛`.

Import supports Beeftext `.btbackup`, `.json`, and `.csv`.
