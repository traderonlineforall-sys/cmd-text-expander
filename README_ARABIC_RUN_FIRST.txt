النسخة دي مبنية على نفس برنامج Beeftext المرفق منك، مع تغيير اسم التشغيل إلى cmd.exe وإضافة ملف الكاندات الحقيقي بتاعك داخل أماكن الداتا المحمولة.

التشغيل المحلي:
1) افتح app\cmd.exe
2) سيب البرنامج شغال
3) جرّب الكيوردات زي Beeftext بالظبط

الرفع على GitHub:
1) ارفع محتويات هذا المجلد على الريبو
2) شغّل GitHub Actions
3) حمّل artifact باسم cmd_beeftext_logic_release
4) فك الضغط وشغّل cmd.exe

لو لقيت الكاندات مش محملة تلقائيًا على جهاز معين:
من داخل البرنامج اعمل Import للملف app\Beeftext.btbackup
